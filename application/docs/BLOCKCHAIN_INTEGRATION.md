# Finex Blockchain Integration (BSC Testnet)

Laravel remains the management layer (registration, genealogy, ROI cron, dashboards, reports, admin).  
**FinexVault** holds USDT and enforces investment, ROI unlock, auto-upgrade, and withdrawal validation on-chain.

## Components

| Piece | Path |
|-------|------|
| Smart contracts | `application/blockchain/contracts/` |
| Hardhat project | `application/blockchain/` |
| Operator CLI (Node/ethers) | `application/blockchain/scripts/operator-cli.js` |
| Laravel bridge | `application/app/Services/Blockchain/BlockchainService.php` |
| ROI unlock rule | `application/app/Services/RoiUnlockService.php` |
| Config | `application/config/blockchain.php` |
| SQL columns | `application/database/sql/2026_08_01_blockchain_sync_columns.sql` |

## Business rules on-chain

1. **Investment** — User approves USDT → `FinexVault.invest(slot, sponsor, offchainId)`. Funds stay in the vault.
2. **Daily ROI** — Generated by existing `act:processdaily` cron; totals synced via `syncRoi`.
3. **ROI unlock** — `withdrawable = min(roiGenerated, qualifyingDirects * packageAmount)` where directs have same-or-greater package.
4. **Sponsor Wallet** — Total business / auto-upgrade used / available (available funded by existing 2nd/3rd direct % from `config/income.php`).
5. **Auto Upgrade** — When available ≥ next slot price, next slot activates automatically (no manual purchase).
6. **Withdrawal** — Laravel validates → `processWithdrawal` → vault sends USDT net of 10% fee to user wallet.

## Deploy to BSC Testnet

```bash
cd application/blockchain
npm install
cp ../.env.example ../.env   # set BLOCKCHAIN_OPERATOR_KEY (funded testnet key)
DEPLOY_MOCK_USDT=1 npx hardhat run scripts/deploy.js --network bscTestnet
```

Copy printed addresses into `.env`:

```env
BLOCKCHAIN_ENABLED=true
BSC_CHAIN_ID=97
BSC_TESTNET_RPC=https://data-seed-prebsc-1-s1.binance.org:8545
FINEX_VAULT_ADDRESS=0x...
BLOCKCHAIN_USDT_ADDRESS=0x...   # MockUSDT from deploy
BLOCKCHAIN_OPERATOR_KEY=0x...   # never commit
BLOCKCHAIN_WITHDRAWALS_VIA_VAULT=true
BLOCKCHAIN_SYNC_ROI=true
BLOCKCHAIN_SYNC_AUTO_UPGRADE=true
```

Apply SQL:

```bash
# phpMyAdmin or mysql client
source database/sql/2026_08_01_blockchain_sync_columns.sql
```

## Mainnet

1. Set `BSC_CHAIN_ID=56`, mainnet RPC, real USDT `0x55d398326f99059fF775485246999027B3197955`.
2. Deploy FinexVault **without** MockUSDT (`DEPLOY_MOCK_USDT` unset, `USDT_CONTRACT` set).
3. Keep operator key secure (KMS/HSM recommended).
